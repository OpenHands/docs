Use `ask_oracle` when the active agent should ask a stronger or more specialized saved LLM profile for a second opinion without switching its own active profile.

## When to Use It

`ask_oracle` is useful when an agent is stuck, comparing approaches, or wants another model to review a risky decision. The Oracle call is stateless from the Oracle's point of view: it receives a dedicated Oracle system prompt plus the agent's question and optional context, returns a text recommendation, and does not take over the conversation.

## Configure the Oracle Profile

The Oracle model is resolved **by convention**: a saved LLM profile named `oracle` (see [LLM Profile Store](/sdk/guides/llm-profile-store)). Save a profile under that name and the tool picks it up automatically — there is no dedicated settings field to wire.

```python icon="python" wrap
from pydantic import SecretStr
from openhands.sdk import LLM
from openhands.sdk.llm.llm_profile_store import LLMProfileStore
from openhands.tools.ask_oracle import ORACLE_PROFILE_NAME

store = LLMProfileStore()
store.save(
    ORACLE_PROFILE_NAME,
    LLM(
        model="openai/gpt-5.5",
        api_key=SecretStr("sk-..."),
        usage_id="oracle",
    ),
    include_secrets=True,
)
```

Then add the tool to your agent by name:

```python icon="python" wrap
from openhands.sdk import Agent, Tool

agent = Agent(llm=primary_llm, tools=[Tool(name="ask_oracle")])
```

If no `oracle` profile is saved when the tool is invoked, it returns an error observation telling the agent the Oracle is unavailable. The active conversation LLM is never switched.
