### Pausing Execution

Request a pause from another thread using `conversation.pause()`. A pause is
cooperative: it takes effect at the next step boundary, never in the middle of a
step. Until then the conversation is `PAUSING`. At the boundary, the outcome
depends on how the step ended:

- The agent still has work to do: the conversation becomes `PAUSED` and emits a
  `PauseEvent`. Call `conversation.run()` to resume.
- The agent finished its answer: the conversation stays `FINISHED`. There is
  nothing left to pause, and no `PauseEvent` is emitted. If a message was queued
  during that step, the conversation becomes `PAUSED` instead so that resuming
  picks the message up.
- The step requires confirmation: the conversation stays
  `WAITING_FOR_CONFIRMATION`. A pause does not approve pending actions.
- The step failed: `ERROR` (or `STUCK`) is preserved.

How long `PAUSING` lasts depends on the agent and the run mode:

- With the synchronous `conversation.run()`, the state lock is held for the whole
  step, so `pause()` blocks until the current step completes and the pause lands
  almost immediately after it returns.
- With `arun()`, `pause()` returns at once and the conversation is `PAUSING`
  until the in-flight step completes.
- For an ACP agent, one step is the entire remote prompt turn, which can run many
  tool calls over minutes. Tool calls keep running during `PAUSING`; the next
  queued prompt waits until you resume. To stop the turn itself, use
  `conversation.interrupt()`, which cancels the in-flight `arun()`.

Always wait for the running thread to finish and check the status before
inspecting the workspace, approving actions, or resuming. For an ACP agent the
`thread.join()` below can take as long as the current prompt turn.

```python icon="python" wrap
import threading
import time

thread = threading.Thread(target=conversation.run)
thread.start()

print("Letting agent work for 5 seconds...")
time.sleep(5)

print("Pausing the agent...")
conversation.pause()
thread.join()  # returns once the step boundary is reached
print(f"Status after pause: {conversation.state.execution_status}")

print("Waiting for 5 seconds...")
time.sleep(5)

print("Resuming the execution...")
conversation.run()
```

### Pausing Through the Agent Server

`POST /api/conversations/{id}/pause` requests the same cooperative pause. While a
pause is pending, REST responses, WebSocket state updates, and webhooks keep
reporting `running`; they report `paused` only once the step has actually
stopped. The conversation webhook fired by `/pause` therefore still carries
`running`; watch the event stream (`ConversationStateUpdateEvent` with
`execution_status`) for the transition to `paused`. Searches and counts filtered
by `running` include pending pauses, and a second `/run` while the original run
is still active returns HTTP 409.

If the Agent Server restarts while a conversation is pausing, that stale active
state is recovered as `error`, exactly like an interrupted `running`
conversation. The interrupted prompt is not replayed automatically.

The Python SDK and TypeScript client already accept a `pausing` execution status
in addition to `running`. Treat both as active work: neither means the agent has
stopped modifying the workspace. Servers do not emit `pausing` yet; when they do,
it will be announced in the release notes.

## Ready-to-run Example

<Note>
This example is available on GitHub: [examples/01_standalone_sdk/09_pause_example.py](https://github.com/OpenHands/software-agent-sdk/blob/main/examples/01_standalone_sdk/09_pause_example.py)
</Note>

Pause agent execution mid-task by calling `conversation.pause()`:

```python icon="python" expandable examples/01_standalone_sdk/09_pause_example.py
import os
import threading
import time

from pydantic import SecretStr

from openhands.sdk import (
    LLM,
    Agent,
    Conversation,
)
from openhands.sdk.tool import Tool
from openhands.tools.file_editor import FileEditorTool
from openhands.tools.terminal import TerminalTool


# Configure LLM
api_key = os.getenv("LLM_API_KEY")
assert api_key is not None, "LLM_API_KEY environment variable is not set."
model = os.getenv("LLM_MODEL", "anthropic/claude-sonnet-4-5-20250929")
base_url = os.getenv("LLM_BASE_URL")
llm = LLM(
    usage_id="agent",
    model=model,
    base_url=base_url,
    api_key=SecretStr(api_key),
)

# Tools
tools = [
    Tool(
        name=TerminalTool.name,
    ),
    Tool(name=FileEditorTool.name),
]

# Agent
agent = Agent(llm=llm, tools=tools)
conversation = Conversation(agent, workspace=os.getcwd())

print("=" * 60)
print("Pause and Continue Example")
print("=" * 60)
print()

# Phase 1: Start a long-running task
print("Phase 1: Starting agent with a task...")
conversation.send_message(
    "Create a file called countdown.txt and write numbers from 100 down to 1, "
    "one number per line. After you finish, summarize what you did."
)

print(f"Initial status: {conversation.state.execution_status}")
print()

# Start the agent in a background thread
thread = threading.Thread(target=conversation.run)
thread.start()

# Let the agent work for a few seconds
print("Letting agent work for 2 seconds...")
time.sleep(2)

# Phase 2: Pause the agent
print()
print("Phase 2: Pausing the agent...")
conversation.pause()

# Wait for the thread to finish (it will stop when paused)
thread.join()

print(f"Agent status after pause: {conversation.state.execution_status}")
print()

# Phase 3: Send a new message while paused
print("Phase 3: Sending a new message while agent is paused...")
conversation.send_message(
    "Actually, stop working on countdown.txt. Instead, create a file called "
    "hello.txt with just the text 'Hello, World!' in it."
)
print()

# Phase 4: Resume the agent with .run()
print("Phase 4: Resuming agent with .run()...")
print(f"Status before resume: {conversation.state.execution_status}")

# Resume execution
conversation.run()

print(f"Final status: {conversation.state.execution_status}")

# Report cost
cost = llm.metrics.accumulated_cost
print(f"EXAMPLE_COST: {cost}")
```
