# Agent Canvas 1.41.0

Released November 16, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.41.0).

## Highlights

- **Reasoning effort for ACP agents** — Pick the reasoning effort an ACP agent reports, from the composer in a conversation or from **Settings → Agent**. The effort is stored as `acp_effort` on the ACP profile. See [Switching agent or model later](/openhands/usage/agent-canvas/acp-agents#switching-agent-or-model-later).
- **Group the automations dashboard by tag** — A **Group by** dropdown next to Filters switches the dashboard list between status and tag sections. See [Group by status or tag](/openhands/usage/agent-canvas/managing-automations#group-by-status-or-tag).
- **Assisted templates open in the setup view** — Templates that finish setup in a conversation open the two-panel automation setup view, with the seed as the first message and the automation draft beside the chat. The **GitHub CVE Remediation Factory** template is the first Suggested template. See [Templates](/openhands/usage/agent-canvas/prebuilt-automations#templates).
- **Apps enable with secret consent** — Enabling an app that needs a secret reuses the Agent Profiles secret scope list to choose the secrets the app can use, then starts the app automatically. See [Enable and Manage Apps](/openhands/usage/agent-canvas/canvas-extensions#enable-and-manage-apps).
- **Secure replacement of requested secrets** — A `request_secret` call for a name that already exists stays pending until you answer, and the request card never prefills the stored value. See [Agent-Requested Secrets](/openhands/usage/settings/secrets-settings#agent-requested-secrets).
- **Mobile conversation navigation stays visible** — The conversation header and navigation stay visible while you scroll on a phone, and the web app manifest supports a standalone install. See [Phone & Tablet Access](/openhands/usage/agent-canvas/mobile-access#mobile-conversation-navigation).

## Fixes

- Catalog removal and restriction feedback, and confirmation modal descriptions, are readable in every theme.
- Deleting a conversation removes all of its pages with one captured backend scope.
- Conversations start when Canvas is served over plain HTTP on a non-loopback address, where `crypto.randomUUID` is unavailable.
- The MCP OAuth flow sends the browser's backend URL as the callback base.
- ACP login status refreshes on focus and remount without a full Canvas reload.
- On Cloud, `agent_settings.agent_kind` is synced with the active profile after activation and save.
- The mobile automation setup panel stays mounted, so switching between Form and Conversation keeps unsaved fields.
- An open combobox listbox takes Escape before the surrounding dialog closes.
- The Available Hooks dialog names the workspace and user hook file locations.
- The Helm chart notes no longer reference a stale `session-api-key.txt` path.

## Maintenance

- Canvas advances its Debian snapshot to 2026-11-14 for `linux-libc-dev` security fixes.
- Dependency bumps (`lucide-react`, `tanstack`, `framer-motion`, `posthog-js`, `vite`, `zustand`, `i18next`, `eslint`, `msw`, `ws`, `downshift`, `driver.js`, `@microlink/react-json-view`, `electron`) and test/skill maintenance.
