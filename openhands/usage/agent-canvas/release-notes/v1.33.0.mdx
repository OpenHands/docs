# Agent Canvas 1.33.0

Released October 23, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.33.0).

## Highlights

- **DigitalOcean web build keeps you signed in across restarts** — The web build now saves DigitalOcean sign-ins on the machine that runs Canvas: the macOS Keychain or Secret Service (`secret-tool`) when available, then a file encrypted with `OH_SECRET_KEY`, then memory only with a "not saved" warning. The panel shows where the sign-in is kept, along with the team and email. See [Persist Sign-In Across Restarts](/openhands/usage/agent-canvas/backend-setup/digitalocean#persist-sign-in-across-restarts).
- **New DigitalOcean agents default to the smallest size** — The Sandbox size picker preselects the smallest size instead of **Default (DigitalOcean picks)**, which remains an explicit option. If the size catalog fails to load, you must choose a size. See [Create an Agent](/openhands/usage/agent-canvas/backend-setup/digitalocean#3-create-an-agent).
- **Secret values masked in the UI** — Secret value fields in the agent secret-request card and in the `Settings > Secrets` add and edit forms are password inputs, hidden by default with an eye button to reveal the current input. See [Secrets Management](/openhands/usage/settings/secrets-settings).

## Fixes

- Live automation runs render the `current_phase` string that the automation service sends. See [Run Phase](/openhands/usage/agent-canvas/managing-automations#run-phase).
- New DigitalOcean agents default to the smallest VM instead of **Default (DigitalOcean picks)**.
- Secret values are masked in agent secret-request cards and in the `Settings > Secrets` add and edit forms.
- A verify-openhands viewport fix.

## Maintenance

- In-repo map maintenance and removal of the README beta badge.
- CSS refactors and a restyle of the automation template filter chips into a draggable scroll rail.
- Tabs ("Native Integration" / "MCP Server") in the setup choice modal.
