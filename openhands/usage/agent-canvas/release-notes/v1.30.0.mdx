# Agent Canvas 1.30.0

Released October 22, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.30.0).

## Highlights

- **Built-in integration connection state in the setup choice modal** — When you start a recommended automation that can use a built-in integration (GitHub, GitLab, Jira, or Slack), the "Choose your setup" modal reflects whether the integration is connected. A connected integration shows how to use OpenHands in that tool; an integration that is not connected offers **Connect to {name}**; a disabled integration falls back to the MCP options. See [Setup a Pre-built Automation](/openhands/usage/agent-canvas/prebuilt-automations).
- **Cloud members pick the LLM profile on Home** — On an OpenHands Cloud or Enterprise backend, an organization member can choose an LLM profile on Home for a single conversation. The pick applies only to the new conversation and does not change the organization's active profile. See [Manage LLM Profiles](/openhands/usage/agent-canvas/llm-profiles).
- **Getting started checklist hidden on a canvas locked to a Cloud host** — On a canvas that is locked to a Cloud host, the Getting started checklist is never shown, including on Enterprise installs. Local Canvas keeps the checklist. See [First Time Setup](/openhands/usage/agent-canvas/first-time-setup#getting-started-checklist) and [Application Settings](/openhands/usage/settings/application-settings#getting-started-checklist).
- **`default` agent-profile rules scoped to local backends** — The special handling of a profile named `default` applies only to local backends. On Cloud, a profile named `default` behaves like any other profile. See [Agent Profiles](/openhands/usage/agent-canvas/agent-profiles).

## Fixes

- The sidebar conversation list refreshes when a cloud start task becomes ready.
- Workspace grouping persists through server-side conversation tags, so grouping follows the workspace across browsers and devices.
- Azure DevOps repository links open the repository's `_git` page.
- The default primary color is white.
- The DigitalOcean web bridge requires an explicit `MARS_WEB=1` opt-in again.

## Maintenance

- Bumped `@openhands/extensions` to 0.33.0.
- Fixed a shell-quoting problem in the Debian snapshot defaults CI step.
