# Agent Canvas 1.40.0

Released November 12, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.40.0).

## Highlights

- **Clearer Codex subscription guidance** — When onboarding Codex on a containerized backend, the `CODEX_AUTH_JSON` credential help explains that it is required only for a ChatGPT subscription login, and that `OPENAI_API_KEY` users can leave it blank. A "Configure a subscription agent" onboarding link points to the Agent settings page (`/settings/agents`). See [Onboarding an ACP agent](/openhands/usage/agent-canvas/acp-agents#onboarding-an-acp-agent).

## Fixes

- Chat history keeps messages at tied page boundaries.
- Delayed chat echoes no longer delete newer drafts.
- The home model pick activates when a self-hosted instance turns Agent Profiles off.
- Git uses a repository's real default branch instead of assuming `main`.
- Indonesian translations for the Codex subscription keys are added.

## Maintenance

- Dependency bumps across the i18next, tanstack, Mermaid, PostHog, lucide-react, and other groups.
- Review artifact cleanup is absorbed into release PRs.
