# Agent Canvas 1.38.0

Released November 10, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.38.0).

## Highlights

- **Conversation budget meter** — Use the `Usage` meter to compare a conversation's spending with a configured budget cap. The meter reports usage and does not enforce a limit, so spending and the displayed percentage can both pass the cap. Without a cap, the meter is hidden. See [Conversation Budget Display](/openhands/usage/agent-canvas/conversations#conversation-budget-display).
- **Agent Profiles for prompt and plugin presets** — On an automation service that advertises `presetAgentProfiles`, choose an Agent Profile for a prompt or plugin preset instead of a separate model. An ACP profile shows `ACP` in place of an LLM model name. See [Create an automation with the setup assistant](/openhands/usage/agent-canvas/managing-automations#create-an-automation-with-the-setup-assistant).
- **Edit plugin configuration from Edit** — For a plugin-spec automation on a service that advertises `pluginConfigUpdate`, `Edit` shows the executable configuration as JSON. Review proposals from the setup help conversation, adjust the JSON, then save the configuration and trigger together. See [Edit an automation](/openhands/usage/agent-canvas/managing-automations#edit-an-automation).
- **Stop the agent without stopping the sandbox** — `Stop` in the composer interrupts the agent and leaves its sandbox running. On a Cloud backend, use the separate `Stop Sandbox` action when you want to pause the sandbox. See [Stop an Agent or Sandbox](/openhands/usage/agent-canvas/conversations#stop-an-agent-or-sandbox).
- **Reopen a resolved conversation** — On a local Agent Server, a conversation tagged as resolved shows a banner above the composer. Select `Reopen` or send a new message to continue the thread. See [Reopen a Resolved Conversation](/openhands/usage/agent-canvas/conversations#reopen-a-resolved-conversation).
- **Paper theme** — Choose the new `Paper` theme from `Settings > Application > Color Theme`. The Light+ and Solarized themes also finished a contrast pass. The default theme has not changed. See [Choose a Color Theme](/openhands/usage/agent-canvas/customize-and-settings#choose-a-color-theme).
- **Automation install and message-only launch links** — Add `mode=automation` to a single-plugin `/launch` URL to offer `Install Automation` instead of starting a conversation, or share a `message`-only link with no plugin at all. See [Install a Plugin Automation](/openhands/usage/cloud/plugin-launcher#install-a-plugin-automation) and [Start With Only a Message](/openhands/usage/cloud/plugin-launcher#start-with-only-a-message).
- **Enterprise license banner in Canvas** — On an instance-locked OpenHands Enterprise Canvas, a banner reports a missing or expired license and an upcoming trial end. See [Enterprise License Warnings](/openhands/usage/agent-canvas/overview#enterprise-license-warnings).
- **Admins and Owners can edit other people's automations** — Organization Owners and Admins can now edit, turn on, delete, and tag automations that other members created, matching the documented permissions. Members without that permission still act only on automations they created. See [Edit an automation](/openhands/usage/agent-canvas/managing-automations#edit-an-automation).

## Fixes

- Docker keeps new conversation workspaces in the persisted volume, exits non-zero when the agent-server stops responding, and fails fast on unwritable bind mounts.
- Choosing an ACP agent during onboarding saves it to its own profile instead of overwriting `default`.
- A self-hosted instance that turns Agent Profiles off hides the agent profile switch and pill.
- Automation export and import carry the script bundle, automation context is preserved, and help chats open immediately.
- The active LLM profile is reconciled against the backend model, including a race condition.
- Wide-table fades blend into message bubbles, and managed-agent keyboard focus colors are used.
- The Bitbucket Data Center template filter chip is named, the diff viewer releases models after teardown, and the launch view no longer takes focus after you navigate away.

## Maintenance

- Bundled agent-server raised to `1.61.0`.
- Named z-index layers, grid columns, type scale, motion recipes, letter-spacing, and scroll-fade tokens, with lint guards on the cleaned owners.
- Dependency bumps (`@heroui/react`, `framer-motion`, `electron`, `typescript`, `vite`, React Router, TanStack, i18next, `posthog-js`) and artifact cleanup.
