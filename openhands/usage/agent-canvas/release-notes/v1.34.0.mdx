# Agent Canvas 1.34.0

Released October 27, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.34.0).

## Highlights

- **Per-conversation Docker runtime and a Runtime settings page** — On a backend whose Agent Server offers Docker, Home offers `Local`, `Worktree`, and `Docker` for each new conversation, and `Settings > Runtime` sets the default runtime, worktree options, and container memory, CPU, and browser. See [Choose the Runtime per Conversation](/openhands/usage/agent-canvas/backend-setup/docker-execution#choose-the-runtime-per-conversation) and [Settings](/openhands/usage/agent-canvas/customize-and-settings#settings).
- **Automation tags** — Filter the automation dashboard by tag, see tag pills on list rows, cards, detail pages, and pinned Home cards, and edit an automation's tags inline as its creator. Tags are normalized (for example, `Software Factory` becomes `software-factory`). This requires automation `1.26.0` and the optional `/v1/tags` endpoint; without them the UI is unchanged. See [Browse and inspect automations](/openhands/usage/agent-canvas/managing-automations#browse-and-inspect-automations).
- **Custom-script automations can choose their LLM** — The custom-script setup view gains the LLM profile pill, and a new custom automation saves the chosen model. See [Create an automation with the setup assistant](/openhands/usage/agent-canvas/managing-automations#create-an-automation-with-the-setup-assistant).
- **New Conversation in Sandbox** — On Cloud backends, a sidebar row's kebab menu offers `New Conversation in Sandbox`, which starts a new top-level conversation in that row's sandbox and resumes a paused sandbox.
- **"Share with Org users" in team organizations** — On a Cloud backend in a team organization, the conversation share toggle reads `Share with Org users`, and the link is served only to organization members. A Personal Workspace still shows `Public Share`.

## Fixes

- The session API key is passed to the static server through the environment instead of the process arguments.
- The automation KV secret is pinned, so rotating the session key no longer makes existing KV data unreadable.
- Untrusted markdown can no longer set `rel="opener"` or an arbitrary `target`.
- Invalid DigitalOcean OAuth relay attempts no longer end a valid sign-in.
- A replaced socket's late close no longer changes the connection state.
- Escape handling and layout fixes on the automation setup page; the repository menu, model popover, and Event source menu close with Escape.
- Percent-encoded repository labels are decoded.
- Cloud files open correctly in a new window.
- Fixes to profile-list refresh, transcript export, and skill card keys.

## Maintenance

- Raised the minimum Agent Server to `1.57.0`; backends on `1.55` or `1.56` now show the upgrade message.
- Bumped the automation package to `1.26.0` and `@openhands/extensions` to `0.36.0`.
- Removed unused code and the `@react-router/serve` dependency, and bumped `shell-quote` and `DOMPurify`.
- CSS refactors and test and artifact cleanup across the app.
