# Agent Canvas 1.28.0

Released October 19, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.28.0).

## Highlights

- **Bahasa Indonesia (`id`) UI locale** — Bahasa Indonesia joins the Agent Canvas language selector as a fully translated UI language. See [Supported Languages](/openhands/usage/settings/application-settings#supported-languages).
- **Agent-requested secrets, inline in the chat** — The agent can ask for a credential during a conversation with the `request_secret` tool. The request appears as a card in the chat, right after the tool call, with the agent's reason and a prefilled name. Saving attaches the secret to the running conversation and reports only a status to the agent; the secret value never appears in the chat. See [Agent-Requested Secrets](/openhands/usage/settings/secrets-settings#agent-requested-secrets).
- **Reading-pace streaming with word fade-in** — Streamed replies reveal at a steady reading pace with a soft word fade-in, so long answers are easier to follow while they arrive.
- **Getting started checklist close control** — The Getting Started checklist can be dismissed directly. `Settings > Application` remains the source of truth for whether it is shown. See [Application Settings](/openhands/usage/settings/application-settings#getting-started-checklist).
- **Recommended automations on self-hosted instances** — On a cloud backend that reports itself as self-hosted (OpenHands Enterprise), six catalog templates that overlap a built-in integration, need a user-managed secret, or are covered by the Create Automation UI are no longer offered on the Recommended automations surfaces. See [Setup a Pre-built Automation](/openhands/usage/agent-canvas/prebuilt-automations#recommended-automations-on-self-hosted-instances).
- **Azure DevOps repositories from every organization** — On a cloud backend, the Azure DevOps repository picker uses the same installation flow as GitHub and lists repositories from every organization the user belongs to, instead of only the first.
- **Missing-runtime conversations presented as archived** — A conversation whose runtime is missing (rather than errored) is hidden by default, appears under `Show archived` with the `Archived` chip, and offers no archive action in its menu. See [Archive a Conversation](/openhands/usage/agent-canvas/conversations#archive-a-conversation).
- **Agent profile kept on per-launch LLM picks and in `/new`** — A named OpenHands profile keeps its agent profile when you pick an LLM for a single launch, and `/new` and local child conversations launch from the active or parent profile. See [Agent Profiles](/openhands/usage/agent-canvas/agent-profiles).

## Fixes

- Resuming a paused cloud conversation wakes the sandbox instead of failing, and a message sent while a cloud sandbox is starting is held and delivered when the runtime becomes reachable.
- Azure DevOps repository listing on a cloud backend now covers every organization the user belongs to.
- A conversation whose runtime is missing is treated as archived everywhere, while an errored conversation stays visible with its error indicator.
- Local plugin launches with unsupported parameters are rejected with an explanation instead of silently discarding the configuration. See [Plugins in Agent Canvas](/openhands/usage/agent-canvas/plugins#local-launch-parameters).
- Removed unreachable sections from the conversation overview drawer.
- Theme, readability, and accessibility fixes across backends, settings, automations, chat, markdown tables and links, toasts, critic results, hook diagnostics, right-to-left switch thumbs, and phone-width modals.
- Settings and profile form fixes: new LLM profile values and application edits are preserved after a failed save, taken names show dedicated messages, the active backend's values show after a switch, 4xx save responses are not retried, and the server's save-failure reason is shown.
- Automations keep the existing bundle when editing a custom automation, show the reason when a draft save is refused, show saved draft errors before historical test status, and start a Custom schedule from the preset it replaces.

## Maintenance

- Bumped agent-server to 1.55.0 and 1.55.1.
- Bumped the automation package to 1.21.0.
- Updated the in-repo `verify-openhands` skill and its feature map.
