# Agent Canvas 1.25.0

Released October 6, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.25.0).

## Highlights

- **Model Router settings** — Configure routers that route each task to the right LLM profile, with a **Run on first message** toggle that routes the first message of every new conversation. See [Configure a Model](/openhands/usage/agent-canvas/model-configuration#model-router).
- **Bulk-add provider models as LLM profiles** — Create several LLM profiles at once from a provider picker, optionally binding them to a provider connection so they inherit its credentials. See [Manage LLM Profiles](/openhands/usage/agent-canvas/llm-profiles#bulk-add-models-as-profiles).
- **Agent profile persona and instructions** — Give a profile its own system prompt, choosing between the OpenHands default, added instructions, or a custom persona. See [Agent Profiles](/openhands/usage/agent-canvas/agent-profiles#set-a-profiles-system-prompt).
- **Voice input** — An optional microphone button in the chat input, backed by browser speech recognition or an OpenAI-compatible transcription endpoint. See [Conversations](/openhands/usage/agent-canvas/conversations#voice-input).
- **Workspace file discovery** — Configure which files the Files panel discovers per workspace, including excluded directories, included symlinks, and a file-count limit. See [Conversations](/openhands/usage/agent-canvas/conversations#file-discovery).
- **Update installed Apps** — Update an app installed from a local path or Git in place, without uninstalling and reinstalling it. See [Apps (Beta)](/openhands/usage/agent-canvas/canvas-extensions).
- **Automations dashboard filter by creator** — Filter the Automations dashboard by anyone, you, or others. See [Managing automations](/openhands/usage/agent-canvas/managing-automations).

## Fixes

- Agent profiles pick their tools from the server's catalog, so the available tool list follows the connected server.
- Automation templates are offered on cloud backends, and the built-in integration is offered before issue-to-PR templates.
- Conversation title generation uses the running agent profile's LLM.
- Focused settings pages keep their keyboard and viewport behavior on narrow screens.

## Maintenance

- Pinned agent-server and SDK to 1.53.0, with Extensions and Automation dependency bumps.
