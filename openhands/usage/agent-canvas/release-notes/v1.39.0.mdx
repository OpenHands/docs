# Agent Canvas 1.39.0

Released November 11, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.39.0).

## Highlights

- **Automations dashboard filter by owner with a Service accounts option** — The dashboard's "Filter by creator" becomes "Filter by owner". **Me** and **Others** match people only, and a **Service accounts** option lists automations that run as a service account. The option appears only when the instance reports service accounts enabled. See [Managing automations](/openhands/usage/agent-canvas/managing-automations#filter-by-owner).
- **Paper theme reads as aged newsprint with readable warnings** — The Paper theme's palette, code, diff, and terminal syntax colors, and its link role are reworked for contrast and a warm print feel. Warning text and automation health dots are now readable on every Paper surface.
- **Stop-hook feedback stays in the hook row** — The SDK's `[Stop hook feedback]` message is no longer repeated in the chat. The `Hook: Stop blocked` row still shows the reason and context when expanded.
- **Tighter message hover timestamps** — The message hover timestamp sits closer to its message.

## Fixes

- Chat resume visibility timestamps are interpreted as UTC.
- Filtered sub-conversations are memoized in the websocket provider.
- Chat is delivered over HTTP until the session socket is served.
- The populated Event Key dropdown opens correctly.
- Automations respect backend profile selection availability.
- The setup guide starts the tour in an open dialog and ends it when that dialog closes, and drops an unanswered close question when the guide hides.
- A missing event file no longer crashes the UI.

## Maintenance

- Bundled agent-server raised to `1.62.0`, automation to `1.32.1`, and `@openhands/extensions` to `0.42.0`.
- Dependency bumps and removal of merged PR artifacts.
