# Agent Canvas 1.37.0

Released November 6, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.37.0).

## Highlights

- **Every automation explains itself** — The automation detail view leads with a description: the automation's own, or its catalog template's when the automation has none. Without either, a generated `How it runs` flow summarizes the trigger and action. A template description also shows the template's diagram when the published catalog supplies one. See [Browse and inspect automations](/openhands/usage/agent-canvas/managing-automations#browse-and-inspect-automations).
- **Template descriptions in the setup form** — Direct form setup shows the template's description, and its diagram below it when the catalog entry includes one. See [Pre-built Automations](/openhands/usage/agent-canvas/prebuilt-automations#how-creation-flows-usually-start).

## Fixes

- Resumed chat sessions are placed after conversation history using UTC timestamps.
- Generated conversation titles stay visible during startup handoff.
- Empty-chat suggestions wait for session replay instead of flashing.
- The home page loads at a base path without a trailing slash.

## Maintenance

- Live chat updates no longer rescan history repeatedly.
- Existing control corner radii are named, and arbitrary values are rejected in four migrated owners.
- Dependency bumps (`lucide-react`, `driver.js`, `@types/node`) and artifact cleanup.
