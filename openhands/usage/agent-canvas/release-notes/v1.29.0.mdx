# Agent Canvas 1.29.0

Released October 20, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.29.0).

## Highlights

- **Every agent profile owns its settings** — `default` is now an ordinary agent profile that launches by id from its own stored settings instead of from the global settings pages. Skills, MCP servers, and the active LLM profile each have one owner: editing the shared value in either the profile editor or the global page changes both. A new profile starts from `default`, and `default` cannot be renamed or deleted. See [Agent Profiles](/openhands/usage/agent-canvas/agent-profiles).
- **Skills, condenser, verification, and Model Router per profile** — The agent profile editor gains a **Skills** section that lists loadable skills from the agent-server's skill catalog, plus **Condenser**, **Verification**, and **Model Router** sections. A new profile starts from the global values and stores its own once edited. The critic API key stays global and never reaches a profile. See [Agent Profiles](/openhands/usage/agent-canvas/agent-profiles) and [Configure a Model](/openhands/usage/agent-canvas/model-configuration#model-router).
- **Dismiss the Recommended automations rail** — The **Recommended automations** rail on Home can be dismissed with a hover-revealed `X` control. Restore it from `Settings > Application` with the **Show Recommended automations** switch, which sits next to **Show getting started checklist**. See [Application Settings](/openhands/usage/settings/application-settings).
- **Full organization names in the backend selector** — The backend selector shows each organization's full name instead of an abbreviated label.

## Fixes

- Automations no longer offer an agent profile to prompt and plugin presets, which do not support one.
- The LLM provider picker is filtered and sorted as you type.
- The launcher pins `uvx` to Python 3.12–3.14 until the SDK's compiled dependencies ship Python 3.15 wheels, so a machine without a system Python no longer fails to start the agent-server or automation backend.
- The first-run modal is skipped on a canvas locked to a Cloud host, and the setup guide closes from its close button.
- A connected repository is saved on the cloud conversation, and the first Cloud message is kept when the history page lags the runtime.
- The npm library ships a scoped stylesheet, git chip icons are visible in light themes, and the chat catches up with the model within a second instead of ten.
- Markdown alerts use readable theme roles, and failed health dots use semantic colors.

## Maintenance

- Bumped `@openhands/extensions` to 0.32.0.
- The Docker image build verifies the agent-server version, and the macOS release surfaces the unquarantine workaround for the ad-hoc-signed desktop build.
