# Agent Canvas 1.32.0

Released October 23, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.32.0).

## Highlights

- **MCP library install dialog offers a connection method** — When a library entry has more than one installable option, its install dialog now shows a **Connection method** tab row, with the first option selected. For example, Sentry offers **OAuth sign-in** and **API key or token**; the token option, with an optional `SENTRY_HOST`, works with a self-hosted Sentry server. Entries with a single installable option look and behave as before. See [Choose a Connection Method When Installing](/openhands/usage/settings/mcp-settings#choose-a-connection-method-when-installing).
- **Automation repository picker lists every cloneable provider** — The Repositories picker in the automation setup form now lists repositories from each connected provider whose repositories automation runs can clone, instead of GitHub only. With more than one provider connected, a Git provider choice at the top of the list switches between them, with GitHub first. Non-GitHub repositories are stored as their URL on the provider's host; a repository on a connected self-hosted host is sent with its provider so the run authenticates the clone. See [Create an automation with the setup assistant](/openhands/usage/agent-canvas/managing-automations#create-an-automation-with-the-setup-assistant).
- **Pinned automations follow you across browsers** — On a local backend, pins and their order on the Home dashboard are now stored in agent-server settings instead of browser storage, so they appear in every browser and on every device connected to that backend. Existing pins are migrated on first load. Cloud backends and demo mode are unchanged.
- **Quieter backend logs by default** — Agent Canvas now starts its backends at log level `WARNING`, so a default launch no longer prints library-internal startup chatter such as SQLAlchemy mapper lines. Run with `--verbose` to restore `DEBUG` output, and set `LOG_LEVEL` or `AUTOMATION_LOG_LEVEL` to override the level. The Docker entrypoint uses the same default. See [Backend Logs](/openhands/usage/agent-canvas/troubleshooting#backend-logs).

## Maintenance

- Bumped the bundled agent-server to 1.58.1, automation to 1.25.1, and `@openhands/extensions` to 0.35.0.
- Enforced a seven-day minimum release age for third-party dependencies.
