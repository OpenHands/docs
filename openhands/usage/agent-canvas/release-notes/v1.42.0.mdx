# Agent Canvas 1.42.0

Released November 18, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.42.0).

## Highlights

- **Pick the exact connected git provider for a repository**: On a Cloud instance with more than one linked connection of the same git provider type, the repository picker lists each connection by its title. Conversations started from that selection clone from the selected connection's host with its credentials.

## Fixes

- Filter menus close on Escape, return focus to the trigger, and leave a surrounding dialog open.
- The webhook source ID field uses the browser's native format check, so a malformed ID is blocked before the form is submitted.
- Copy buttons fall back to a legacy copy method when the async Clipboard API is unavailable, such as over plain HTTP, and report success only when the text reaches the clipboard.

## Maintenance

- Dependency bumps (`i18next`, `framer-motion`, `downshift`, `axios`, `vite`, `posthog-js`, `isbot`, `electron`, `lucide-react`, `@microlink/react-json-view`, `eslint`, `@testing-library/user-event`) and `verify-openhands` skill map maintenance.
