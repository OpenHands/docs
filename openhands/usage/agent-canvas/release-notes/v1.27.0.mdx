# Agent Canvas 1.27.0

Released October 12, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.27.0).

## Highlights

- **Pi and OpenCode ACP agents** — Pi and OpenCode join Claude Code, Codex, and Gemini CLI as built-in ACP providers, available on local backends (your machine or a self-hosted Agent Server). See [ACP Agents](/openhands/usage/agent-canvas/acp-agents).
- **Agent-reported ACP models** — On a local backend, Agent Canvas asks the agent-server which models a provider offers, so account-dependent catalogs show what you can actually run. Settings gains an **Agent default** option. See [ACP Agents](/openhands/usage/agent-canvas/acp-agents#switching-agent-or-model-later).
- **DigitalOcean Managed Agents backend** — Connect Agent Canvas to DigitalOcean Managed Agents, create or select an OpenHands agent and session, and use it as a backend. See [DigitalOcean Managed Agents](/openhands/usage/agent-canvas/backends#digitalocean-managed-agents).
- **Automation setup assistant** — A split setup form and conversation, where OpenHands can fill the form fields, plus persisted drafts you can reopen, test, and create from. See [Create an automation with the setup assistant](/openhands/usage/agent-canvas/managing-automations#create-an-automation-with-the-setup-assistant).
- **Splash-page mode toggle** — Toggle automation mode from the home/splash page to reach the automation entry point.

## Fixes

- Compact section navigation on tablets in settings and customize views.
- Hooks, MCP, settings, onboarding tour, theme, accessibility, telemetry, and i18n fixes, including corrected text and error messages in the Available Hooks dialog.

## Maintenance

- Bumped agent-server to 1.54.0 (SDK ACP model discovery), with dependency and lint updates.
