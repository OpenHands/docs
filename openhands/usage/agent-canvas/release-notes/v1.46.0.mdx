# Agent Canvas 1.46.0

Released November 25, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.46.0).

## Highlights

- **Find, open, and unshare the conversations shared with your team org**: The conversation list has a `Private` / `Shared` toggle. `Shared` lists what members shared with the organization, most recently updated first, loads the next 20 with `Load more`, and gives an owner a row menu that stops sharing without opening the conversation. An Org Admin can hide the list for the organization. See [Find Shared Conversations](/openhands/usage/agent-canvas/conversations#find-shared-conversations).
- **Send feedback from the home screen**: A `Feedback` button opens a form with a required message and an optional email address. Submitting sends the text to the feedback survey configured for the deployment, without linking it to an analytics identity. See [Send Feedback From Canvas](/openhands/usage/agent-canvas/troubleshooting#send-feedback-from-canvas).
- **Keep Git Sync activation status out of the repository**: The `Keep automation activation status local` switch in the Git Sync form lets each backend decide which automations run while Git records what they do. See [Keep Activation Status Local](/openhands/usage/agent-canvas/git-sync#keep-activation-status-local).

## Maintenance

- Component bumps: agent-server to 1.64.1, automation to 1.36.0, extensions to 0.44.0.
- Dependency bumps: `@tanstack/react-virtual`, `electron` 45.3.2 → 45.3.4, `posthog-js` 1.450.0 → 1.450.1, `@microlink/react-json-view`, `lucide-react` 1.73.0 → 1.74.0, and the `i18next` and `eslint` groups.

## Install Note

The macOS build is not signed with an Apple Developer ID, so macOS can report the downloaded app as damaged. Clear the quarantine attribute once; see [Desktop App](/openhands/usage/agent-canvas/setup#troubleshooting-and-lifecycle).
