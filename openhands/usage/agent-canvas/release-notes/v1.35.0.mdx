# Agent Canvas 1.35.0

Released November 3, 2026.

[View the full release on GitHub](https://github.com/OpenHands/OpenHands/releases/tag/v1.35.0).

## Highlights

- **Home remembers the cloud repository selection** — On a cloud backend, the home launcher keeps the repository and branch you last picked, per backend. A remembered selection is validated in the background; a selection that can no longer be used is dropped without an error, and a clear control removes it. See [Connect and Manage Backends](/openhands/usage/agent-canvas/backends).
- **Automation repository and event handling for self-hosted providers** — A picked Bitbucket Data Center repository is stored as its clone URL, and event-type suggestions follow the selected source so Jira Data Center and Bitbucket Data Center offer their own event types. See [Repository picker providers](/openhands/usage/agent-canvas/managing-automations#repository-picker-providers).
- **Server-side conversation tags** — Workspace and repository metadata, and sidebar pin/archive state, are stored as server-side conversation tags, so grouping, repo and branch badges, and pins and archives survive on a second browser or machine. See [Archive a Conversation](/openhands/usage/agent-canvas/conversations#archive-a-conversation).
- **Download a file from the Files tab** — A **Download** button beside **Open in new window** saves the selected file. Local backends download the original bytes for text, images, PDFs, and binaries; cloud backends save decoded UTF-8 text. See [Files View](/openhands/usage/agent-canvas/conversations#files-view).
- **Resizable sidebar** — Drag the expanded desktop sidebar's right edge to set its width. See [Conversation List Controls](/openhands/usage/agent-canvas/conversations#conversation-list-controls).
- **Clearer chat activity** — Hooks and reasoning group with tool calls, group headers read as sentence-style summaries, a live stage appears in the chat while the agent works, and compact timestamps appear on message hover. See [Follow Agent Activity](/openhands/usage/agent-canvas/conversations#follow-agent-activity).
- **Immediate conversation startup** — Conversations open immediately with inline startup progress, and sidebar rows show startup activity while a cloud sandbox starts.
- **Automation Events page and `keep_alive`** — A manifest-gated **Automate → Events** page lists and registers custom webhook sources, and the automation detail actions menu can keep a sandbox alive after a run. See [Event Sources](/openhands/usage/agent-canvas/automation-events) and [Keep a sandbox alive after a run](/openhands/usage/agent-canvas/managing-automations#keep-a-sandbox-alive-after-a-run).
- **Enterprise organization MCP servers** — On an OpenHands Enterprise instance with organization MCP servers enabled, the **MCP Servers** item opens the instance's `Settings > MCP` page.

## Fixes

- LLM profile deletion reports its reason, and the agent profile pill and hover naming are corrected.
- The git provider dropdown no longer lists non-git entries.
- Model-switch attribution and the Home message pending state are corrected.
- The Cloud file list refreshes, and files outside the workspace open correctly.
- Azure DevOps links and SSH remotes are handled correctly.
- Mobile touch targets and the phone-width Stop control are corrected.
- ACP enabled catalog skills, hook event titles, and the automation template filter scroll are fixed.
- Run is no longer suppressed after a model pick on the home page, and the Creating conversation toast is fixed.
- The received-reply display delay, context compaction errors, and Cloud attachment uploads are fixed.
- Transient connection failures recover, paused sandboxes resume, and terminal output from saved history displays correctly.
- The Thinking flash on replay is removed.
- Launcher port fallback and service restarts are fixed.
- VS Code URL opening, automation setup edits, and the Ask Agent button are fixed.

## Maintenance

- Bundled agent-server raised to `1.59.0` and `@openhands/extensions` to `0.37.0`.
- Dependabot now runs daily, and a Windows npm-install E2E job was added.
- Dependency bumps (React, i18next, `ws`, `docker/login-action`), CSS and theme refactors, artifact cleanup, and recipe refactors.
