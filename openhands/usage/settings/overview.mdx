Agent Canvas is the interface for Agent Canvas (open source), OpenHands Cloud, and OpenHands Enterprise, but the
settings behind it differ by product. Agent Canvas stores settings on each backend you connect to. OpenHands Cloud
and Enterprise store settings in your account on the OpenHands server, and Enterprise adds organization and
installation settings for administrators.

## Where Settings Live

<Tabs>
  <Tab title="Agent Canvas">
    Open **Settings** to choose your model, store secrets, and set agent and application behavior. Open
    **Customize** to manage skills, plugins, and MCP servers. Settings are saved per backend, so each backend you
    connect to keeps its own configuration. See
    [Customize and Settings](/openhands/usage/agent-canvas/customize-and-settings).

    Anyone with the backend's API key can change every setting on that backend.
  </Tab>
  <Tab title="OpenHands Cloud">
    OpenHands Cloud uses the same settings as OpenHands Enterprise, for a single user. Sign in at
    [app.all-hands.dev](https://app.all-hands.dev) and open **Settings** to manage your model, secrets, MCP servers,
    Git integrations, and [API keys](/openhands/usage/settings/api-keys-settings).

    When Agent Canvas connects to an OpenHands Cloud backend, links such as **All Cloud Settings** and
    **Integrations** open these settings in a new tab.
  </Tab>
  <Tab title="OpenHands Enterprise">
    OpenHands Enterprise has three levels of settings. What you can change depends on your role.

    | Level | Who Changes It | Examples |
    |---|---|---|
    | **Personal** | Every user | Personal secrets, personal Agent Profiles, Git integrations, API keys |
    | **Organization** | Owners and Admins | Organization LLM, shared secrets, MCP servers, skills, budgets, members |
    | **Installation** | Super Admins | Instance settings, organizations, users |

    See [Organization Settings](/openhands/usage/cloud/organizations/settings),
    [Secrets Management](/enterprise/secrets-management),
    [Agent Profiles](/enterprise/agent-profiles), and the [Super Admin Dashboard](/enterprise/super-admin).
  </Tab>
</Tabs>

## Settings Pages

| Page | Covers | Products |
|---|---|---|
| [Application Settings](/openhands/usage/settings/application-settings) | Language, budget, Git author, Home display, sandbox grouping | All, with some sections limited to certain products |
| [LLM Settings](/openhands/usage/settings/llm-settings) | Model, API key, and LLM profiles | All |
| [Secrets](/openhands/usage/settings/secrets-settings) | Secrets the agent can use, and Git provider tokens | All. For organization secrets, see [Secrets Management](/enterprise/secrets-management) |
| [MCP Servers](/openhands/usage/settings/mcp-settings) | MCP servers and OAuth connections | All |
| [API Keys](/openhands/usage/settings/api-keys-settings) | Keys for the OpenHands API | OpenHands Cloud and Enterprise |
| [Integrations](/openhands/usage/settings/integrations-settings) | Git providers, Slack, and Jira | OpenHands Cloud and Enterprise |
