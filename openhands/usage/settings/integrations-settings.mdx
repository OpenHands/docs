## Overview

OpenHands offers several integrations, including GitHub, GitLab, Bitbucket, Slack, and Jira, with more to come. Some
integrations, like Slack, are only available in [OpenHands Cloud](/openhands/usage/cloud/openhands-cloud). To save Git
provider tokens as secrets, see
[Configuring Secrets for Common Git Providers](/openhands/usage/settings/secrets-settings#configuring-secrets-for-common-git-providers).

## Self-Hosted Forgejo

Use `FORGEJO_BASE_URL` on the OpenHands app server to set the default Forgejo API URL, such as
`https://forgejo.example.com/api/v1`. A host set in the Forgejo credentials takes precedence. Without either setting,
the app server uses `https://codeberg.org/api/v1`. The Forgejo service uses `FORGEJO_TOKEN` as a fallback when no token
is provided.

Set the host in your Forgejo credentials to use the self-hosted instance for Git operations. If the host uses plain
HTTP on a trusted internal network, set `ALLOW_INSECURE_GIT_ACCESS=true` on the app server.

## OpenHands Cloud Integrations Settings

<Note>
  These settings are only available in [OpenHands Cloud](/openhands/usage/cloud/openhands-cloud).
</Note>

Set up these integrations from OpenHands Cloud:

- [GitHub](/openhands/usage/cloud/github-installation): Install the OpenHands app and [modify repository access](/openhands/usage/cloud/github-installation#modifying-repository-access) at any time.
- [GitLab](/openhands/usage/cloud/gitlab-installation): Connect your GitLab projects.
- [Bitbucket](/openhands/usage/cloud/bitbucket-installation): Connect your Bitbucket repositories.
- [Slack](/openhands/usage/cloud/slack-installation): Install the OpenHands Slack app. Your Slack workspace admin or owner must install it first.
- [Jira Cloud](/openhands/usage/cloud/project-management/jira-integration): Trigger OpenHands from Jira issues. [Jira Data Center and Linear](/openhands/usage/cloud/project-management/overview) are coming soon.
