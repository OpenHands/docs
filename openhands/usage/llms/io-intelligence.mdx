---
title: Use IO Intelligence with OpenHands
description: Configure an IO Intelligence model and API key in Agent Canvas or OpenHands.
---

Use IO Intelligence when you have an io.net API key and want to access a model from its [model catalog](https://io.net/docs/reference/ai-models/get-models-list).

## Configure Agent Canvas

1. Open `Settings > LLM`.
2. Switch to the `Advanced` tab.
3. Set the following:
   - `Custom Model` to the prefix `openai/` + the model ID (e.g. `openai/meta-llama/Llama-3.3-70B-Instruct`)
   - `Base URL` to `https://api.intelligence.io.solutions/api/v1`
   - `API Key` to your IO Intelligence API key
4. Save the profile.
5. Start a new conversation and send a short message to verify the model responds.

IO Intelligence model IDs are Hugging Face-style `org/name` identifiers, for example `deepseek-ai/DeepSeek-R1-0528` or `Qwen/Qwen3-Next-80B-A3B-Instruct`. Copy the exact ID from the [model catalog](https://io.net/docs/reference/ai-models/get-models-list); model availability can change, so do not rely on a previously saved identifier without checking it.

## Fix Common Problems

| Problem | Check | Next step |
|---|---|---|
| Model is not found | The exact IO Intelligence model ID | Copy the ID from the model catalog and re-enter it with the `openai/` prefix in the `Advanced` tab. |
| Authentication fails | The API key | Create or copy an active IO Intelligence API key, then save the profile again. |
| The model does not complete agent tasks reliably | Model context and tool-use support | Choose a more capable model that supports the features required for your task. |

For the broader configuration decision and local/proxy recovery paths, see [Configure a Model](/openhands/usage/agent-canvas/model-configuration). For self-hosted deployments, named `[llm.<profile>]` sections are covered in [Custom LLM Configurations](/openhands/usage/llms/custom-llm-configs).
