## Using Moonshot AI with OpenHands

[Moonshot AI](https://platform.moonshot.ai/) offers several powerful models, including Kimi-K3, which is recommended for use with OpenHands.

### Setup

1. Sign up for an account at [Moonshot AI Platform](https://platform.moonshot.ai/)
2. Generate an API key from your account settings
3. Configure OpenHands to use Moonshot AI:

| Setting | Value |
| --- | --- |
| LLM Provider | `moonshot` |
| LLM Model | `kimi-k3` |
| API Key | Your Moonshot API key |

### Recommended Models

The following models are currently exposed by the Moonshot AI API:

- `moonshot/kimi-k3` - Recommended model.
- `moonshot/kimi-k2.7-code`
- `moonshot/kimi-k2.7-code-highspeed`
- `moonshot/kimi-k2.6`
