title: Use Straitly with OpenHands
description: Configure Straitly as an OpenAI-compatible API gateway in Agent Canvas, OpenHands, or the Agent SDK.
---

Use [Straitly](https://straitly.ai) when you have a Straitly API key and want one OpenAI-compatible endpoint for more than 150 models, including Claude, GPT, Gemini, Grok, and DeepSeek.

## Create an API Key

1. Sign in at [straitly.ai](https://straitly.ai) and create an API key (`STRAITLY_API_KEY`).
2. Browse available model IDs in the [Straitly model catalog](https://straitly.ai/models) or query `GET https://api.straitly.ai/v1/models`.

## Configure Agent Canvas

1. Open `Settings > LLM`.
2. Switch to the `Advanced` tab (or create a reusable [Provider Connection](/openhands/usage/agent-canvas/model-configuration#provider-connection-for-reusable-api-credentials)).
3. Enter the following values and save the profile:

| Setting | Value |
|---|---|
| Custom Model | `openai/<model-id>` (for example, `openai/claude-sonnet-5-5` or `openai/deepseek/deepseek-v4-1-flash-1017`) |
| Base URL | `https://api.straitly.ai/v1` |
| API Key | Your `STRAITLY_API_KEY` |

4. Start a new conversation and send a short message to verify the model responds.

<Note>
  OpenHands uses LiteLLM's OpenAI-compatible route for custom base URLs, so keep the `openai/` prefix before the exact Straitly model ID.
</Note>

## Use It With the SDK

```python
from pydantic import SecretStr
from openhands.sdk import LLM

llm = LLM(
    model="openai/claude-sonnet-5-5",
    base_url="https://api.straitly.ai/v1",
    api_key=SecretStr("<your-straitly-api-key>"),
    usage_id="agent",
)
```

## Fix Common Problems

| Problem | Check | Next step |
|---|---|---|
| Model is not found | The exact Straitly model ID | Check [straitly.ai/models](https://straitly.ai/models) and prefix the ID with `openai/` in `Advanced`. |
| Authentication fails | The `STRAITLY_API_KEY` value | Copy an active key from your Straitly dashboard and save the profile again. |
| Connection error | The Base URL | Confirm `Base URL` is set to `https://api.straitly.ai/v1`. |

For setup details and additional SDK examples, see the [Straitly quickstart](https://straitly.ai/docs/quickstart). For general profile and recovery steps, see [Configure a Model](/openhands/usage/agent-canvas/model-configuration).
