## Using NetMind with OpenHands

[NetMind](https://www.netmind.ai/) provides hosted models through an OpenAI-compatible API. OpenHands connects to NetMind through LiteLLM's OpenAI-compatible provider path.

The following configuration uses `Qwen/Qwen3.8-Flash`, NetMind's current default model.

## Configure Agent Canvas

1. Create a NetMind API key in the [NetMind dashboard](https://www.netmind.ai/).
2. Open `Settings > LLM` in Agent Canvas.
3. Add or edit an LLM profile and select the `Advanced` tab.
4. Enter these values:

| Setting | Value |
|---|---|
| Custom Model | `openai/Qwen/Qwen3.8-Flash` |
| Base URL | `https://api.netmind.ai/inference-api/v1` |
| API Key | Your NetMind API key |

5. Save the profile.
6. Start a new conversation and ask OpenHands to create and read a small file to verify both inference and tool use.

If you plan to use more than one NetMind model, create a Provider Connection named `NetMind`, select `OpenAI` as its provider, and enter the NetMind API key and base URL. NetMind does not appear separately in the supported-provider selector yet. You can then reuse that connection across multiple LLM profiles.

## Configure with Environment Variables

Set the OpenHands LLM variables before starting the backend:

```bash
export LLM_MODEL="openai/Qwen/Qwen3.8-Flash"
export LLM_API_KEY="$NETMIND_API_KEY"
export LLM_BASE_URL="https://api.netmind.ai/inference-api/v1"
```

The `openai/` prefix selects LiteLLM's OpenAI-compatible request path. The model ID sent to NetMind remains `Qwen/Qwen3.8-Flash`.

## Configure with `config.toml`

For a development setup, add the following configuration:

```toml
[llm]
model = "openai/Qwen/Qwen3.8-Flash"
api_key = "YOUR_NETMIND_API_KEY"
base_url = "https://api.netmind.ai/inference-api/v1"
```

<Warning>
Do not commit an API key to source control. Prefer the `LLM_API_KEY` environment variable when the configuration file is shared.
</Warning>

## Known Limitations

- NetMind's OpenAI-compatible `/models` endpoint does not currently provide model discovery. Enter the exact model ID manually.
- This configuration uses LiteLLM's `openai/` compatibility prefix because NetMind is not yet a first-class LiteLLM provider.
- Image input has not been verified for the tested model. Use text-only input unless the selected NetMind model explicitly documents vision support.

## Troubleshooting

| Symptom | Check |
|---|---|
| Authentication error | Confirm the API key is active and available to the OpenHands backend process. |
| Model not found | Use the exact, case-sensitive NetMind model ID after the `openai/` prefix. |
| Connection error | Confirm the base URL includes `/inference-api/v1` and is reachable from the backend or container. |
| Tool calls fail | Use a model that supports tool calling and start a new conversation after changing the profile. |

For general model configuration and recovery steps, see [Configure a Model](/openhands/usage/agent-canvas/model-configuration).
