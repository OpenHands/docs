Use Wallaby when you have a Wallaby API key and want to run Kimi K3 through an OpenAI-compatible endpoint.

## Configure Agent Canvas

1. Create an account at [wallabytoken.com](https://wallabytoken.com/) and mint an API key from the console.
2. Open `Settings > LLM`.
3. In the `Advanced` tab, enter:
   - `Custom Model`: `openai/kimi-k3`
   - `Base URL`: `https://api.wallabytoken.com/v1`
   - `API Key`: your Wallaby API key
4. Save the profile, start a new conversation, and send a short message to verify the model responds.

## Fix Common Problems

| Problem | Check | Next step |
|---|---|---|
| Authentication fails | The API key | Copy an active key from the Wallaby console and save the profile again. |
| Model is not found | The model string | Use `openai/kimi-k3` exactly. The `openai/` prefix routes the request through the OpenAI-compatible endpoint. |
| Cost shows `0.0` in Agent Canvas | The provider's own usage logs | LiteLLM has no price entry for custom models, so check the Wallaby console for the metered bill. |

For the broader configuration decision and local/proxy recovery paths, see [Configure a Model](/openhands/usage/agent-canvas/model-configuration).
