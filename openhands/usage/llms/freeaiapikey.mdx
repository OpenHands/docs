title: Use FreeAIapikey with OpenHands
description: Configure a FreeAIapikey model and API key in Agent Canvas or OpenHands.
---

Use FreeAIapikey when you have a [FreeAIapikey](https://freeaiapikey.com) API key and want to access GPT-5.5, GPT-5.6 Sol, GPT-6 Sol, GPT-6 Astra, Claude Opus 4.7/4.8/5/5.5, or Claude Sonnet 5 through an OpenAI-compatible gateway. The live model catalog is available at `GET https://api.freeaiapikey.com/v1/models`.

## Configure Agent Canvas

1. Open `Settings > LLM`.
2. In the `Advanced` tab, set the base URL to `https://api.freeaiapikey.com/v1` and paste your FreeAIapikey API key (from the [dashboard](https://freeaiapikey.com/dashboard)).
3. Enter the model ID as shown in the catalog, e.g. `openai/gpt-6-sol`.
4. Start a new conversation and send a short message to verify the model responds.

Model availability and IDs can change, so check `GET https://api.freeaiapikey.com/v1/models` rather than relying on a previously saved identifier.

## Fix Common Problems

| Problem | Check | Next step |
|---|---|---|
| Model is not found | The exact model ID from `/v1/models` | Copy the ID from the live catalog and use it in `Advanced`. |
| Authentication fails | The API key | Create or copy an active key from the dashboard, then save the profile again. |
