title: Managing Automations

---

Manage automations in the **Automate** view of Agent Canvas, or ask an agent in any conversation. Both work the same
way in Agent Canvas, OpenHands Cloud, and OpenHands Enterprise. For a full reference of the Automate view, including
filters, tags, exports, and imports, see
[Managing Automations in Agent Canvas](/openhands/usage/agent-canvas/managing-automations).

## Viewing Your Automations

Open **Automate** to see your automations, their triggers, and whether they're enabled. Click an automation to see
its prompt, trigger, model, and recent runs.

You can also ask an agent:

```
List my automations
```

```
Show me the details of the "Daily Report" automation
```

## Enabling and Disabling

Disable an automation to stop its runs without losing its settings. Use the toggle on the automation, or ask:

```
Disable the "Daily Report" automation
```

```
Enable the "Daily Report" automation
```

## Changing the Schedule or Timeout

Edit the automation in **Automate**, or ask:

```
Change the "Daily Report" automation to run at 10 AM instead of 9 AM
```

```
Set the "Weekly Cleanup" automation timeout to 20 minutes
```

The maximum timeout depends on the deployment. Runs that exceed their timeout fail.

## Running Manually

Run an automation outside its schedule to test it or to get a result now. Use the run action on the automation, or
ask:

```
Trigger the "Daily Report" automation now
```

## Viewing Past Runs

A prompt automation starts one conversation per run. A script automation can start no conversations or several.
Conversations that a run starts appear in your conversations list. Open one to see what the agent did, continue the
conversation, or debug a failure. To read a script's own output, use **View logs** on its run.

In an automation's **Activity Log**, use **Export JSON** or **Export CSV** to download its run history.

In OpenHands Enterprise and in OpenHands Cloud team organizations, other organization members can open a run's
conversation in read-only mode. See [Automations in Enterprise](/enterprise/automations) and
[Shared Automation Conversations on Cloud](/openhands/usage/agent-canvas/managing-automations#shared-automation-conversations-on-cloud).

### Run Statuses

- **Pending**: Scheduled, waiting to start.
- **Running**: In progress.
- **Completed**: Finished successfully.
- **Failed**: Stopped with an error. Open the run for details.
- **Cancelled**: Stopped before it finished.
- **Skipped**: Not started, for example because the backend reached its concurrency limit.

## Deleting Automations

Delete an automation from **Automate**, or ask:

```
Delete the "Old Report" automation
```

Deleting an automation is permanent. Disable it instead if you might need it later.
