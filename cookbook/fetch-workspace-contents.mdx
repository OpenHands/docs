On a Docker Compose install of OpenHands Enterprise, the files agents work on
live inside the sandbox containers. This example copies them out of every
sandbox on the host with `docker cp`, for a backup, an audit, or to hand the
work to another tool.

## Where the Workspace Files Live

- **Inside each sandbox container.** Each sandbox is a container named
  `oh-agent-server-<sandbox_id>`, and its files are under `/workspace/project`.
  Repositories are cloned into folders under it.
- **Not in a Docker volume.** The `app-filestore` volume belongs to the app
  server and holds no workspace files. If you set `SANDBOX_VOLUMES` in `.env`,
  the host paths it names are bind-mounted into every sandbox, and you can read
  them on the host directly.
- **Pausing keeps the files, deleting removes them.** Pausing a sandbox stops its
  container, which keeps its filesystem. Deleting a sandbox removes the container
  and its files with it.
- **Conversations can share a sandbox.** The Compose file sets
  `OH_APP_CONVERSATION_SANDBOX_GROUPING_STRATEGY=FEWEST_CONVERSATIONS`, so
  several conversations can share one sandbox and its `/workspace/project`.

## Run It

Run this on the Docker host, or with a `DOCKER_HOST` that points at its daemon:

```bash
./fetch_with_docker.sh ./workspaces
```

```text
3kTq9mYbWZf2  running  48M
7hLp2xRcVd8n  exited  12M
Copied 2 workspace(s) to ./workspaces
```

Each sandbox's files land in `./workspaces/<sandbox_id>/`. It copies every
user's sandboxes, including paused ones, and needs no OpenHands API key. Running
it again refreshes the same folders.

```bash fetch_with_docker.sh expandable
#!/usr/bin/env bash
# Copy the workspace out of every OpenHands sandbox container on this Docker host.
# Works on running and stopped (paused) containers. Needs no OpenHands API key.
set -euo pipefail

OUTPUT_DIR="${1:-${OUTPUT_DIR:-./workspaces}}"
WORKSPACE_PATH="${WORKSPACE_PATH:-/workspace/project}"
CONTAINER_PREFIX="${CONTAINER_PREFIX:-oh-agent-server-}"

mkdir -p "$OUTPUT_DIR"

containers=$(docker ps -a --filter "name=^${CONTAINER_PREFIX}" --format '{{.Names}}')
if [ -z "$containers" ]; then
  echo "No containers named ${CONTAINER_PREFIX}* on this Docker host."
  exit 0
fi

copied=0
for container in $containers; do
  sandbox_id="${container#"$CONTAINER_PREFIX"}"
  state=$(docker inspect --format '{{.State.Status}}' "$container")
  dest="$OUTPUT_DIR/$sandbox_id"
  mkdir -p "$dest"
  # The trailing /. copies the directory's contents, so a second run refreshes
  # the same folder instead of nesting a new copy inside it.
  if docker cp "$container:$WORKSPACE_PATH/." "$dest" 2>/dev/null; then
    echo "$sandbox_id  $state  $(du -sh "$dest" | cut -f1)"
    copied=$((copied + 1))
  else
    rmdir "$dest" 2>/dev/null || true
    echo "$sandbox_id  $state  skipped: $WORKSPACE_PATH not found"
  fi
done

echo "Copied $copied workspace(s) to $OUTPUT_DIR"
```

<Warning>
  Treat the copy as sensitive. It includes each repository's `.git` folder, whose
  `config` can hold the token the repository was cloned with.
</Warning>
