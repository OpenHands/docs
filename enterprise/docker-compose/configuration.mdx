Set these variables in a `.env` file next to `docker-compose.yml`:

```bash .env
WEB_HOST=openhands.example.com
WEB_URL=https://openhands.example.com
AGENT_CANVAS_LOCK_TO_CLOUD=https://openhands.example.com
```

For a Kubernetes installation, see [Helm Configuration](/enterprise/k8s-install/configuration).

## General

| Variable | Default | Description |
| --- | --- | --- |
| `WEB_HOST` | `localhost` | Hostname that users open OpenHands on, such as `openhands.example.com`. |
| `WEB_URL` | `http://localhost:<APP_PORT>` | Full URL that users open, including the scheme and any port. |
| `APP_PORT` | `9043` | Port on the host that serves the stack. |
| `AGENT_CANVAS_LOCK_TO_CLOUD` | `http://localhost:<APP_PORT>` | URL that Agent Canvas connects to. Set it to the same value as `WEB_URL`. |
| `COMPOSE_FILE` | | Compose files to load, separated by colons. Use it to add the [HTTPS overlay](/enterprise/docker-compose/https). |
| `LOG_LEVEL` | `INFO` | Log level: `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |

## Database

The stack runs PostgreSQL in the `db` service. Set these variables before the first start, because
PostgreSQL creates the database and user only once.

| Variable | Default | Description |
| --- | --- | --- |
| `DB_NAME` | `openhands` | Application database. |
| `DB_USER` | `openhands` | Database user. |
| `DB_PASS` | Placeholder | Database password. |

## Users and Organizations

The stack signs users in with an email address and password.

| Variable | Default | Description |
| --- | --- | --- |
| `OPEN_ORG_CREATION_ENABLED` | `false` | Let any signed-in user create an organization. |
| `USER_PROVISIONING_ENABLED` | `false` | Turn on the admin API that creates users without their input. |

## Sandboxes

The stack runs sandboxes as containers on the host's Docker engine.

| Variable | Default | Description |
| --- | --- | --- |
| `OH_SANDBOX_MAX_NUM_SANDBOXES` | `5` | Maximum number of sandboxes that each user can run at once. When a user starts another sandbox, OpenHands pauses their oldest running one. |

## Images

Each release pins these images. Override them only to run a different version or a
[custom sandbox image](/enterprise/custom-sandbox-images/index).

| Variable | Default | Description |
| --- | --- | --- |
| `APP_IMAGE` | Release image | Image for the application and worker. |
| `AUTOMATION_IMAGE` | Release image | Image for the automation service. |
| `AGENT_CANVAS_IMAGE` | Release image | Image for Agent Canvas. |
| `AGENT_SERVER_IMAGE_REPOSITORY` | `ghcr.io/openhands/agent-server` | Repository of the sandbox image. |
| `AGENT_SERVER_IMAGE_TAG` | Release tag | Tag of the sandbox image. |

## Automations

| Variable | Default | Description |
| --- | --- | --- |
| `AUTOMATION_SERVICE_KEY` | Placeholder | Key that the application uses to call the automation service. |
| `AUTOMATION_WEBHOOK_SECRET` | Placeholder | Secret that verifies the signatures of automation webhooks. |
| `AUTOMATION_KV_SECRET` | Placeholder | Key that signs automation KV tokens and encrypts the state that automations store. |
| `AUTOMATION_DB_NAME` | `automations` | Database for the automation service. |

## Email

OpenHands sends email, such as organization invitations, through your SMTP server.

| Variable | Default | Description |
| --- | --- | --- |
| `SMTP_HOST` | | Hostname of your SMTP server. |
| `SMTP_PORT` | `587` | Port of your SMTP server. |
| `SMTP_FROM_EMAIL` | `OpenHands <no-reply@openhands.dev>` | Address that OpenHands sends email from. |
| `SMTP_USE_TLS` | `true` | Upgrade the connection with STARTTLS. |
| `SMTP_USE_SSL` | `false` | Connect over implicit TLS, usually on port 465. When set, OpenHands ignores `SMTP_USE_TLS`. |
| `SMTP_USERNAME` | | SMTP username. Leave it unset for a server that doesn't require authentication. |
| `SMTP_PASSWORD` | | SMTP password. |

## Web Search

| Variable | Default | Description |
| --- | --- | --- |
| `TAVILY_API_KEY` | | Tavily API key. When set, agents can search the web through Tavily without access to the key. |

## Telemetry

See [Telemetry](/enterprise/docker-compose#telemetry).

| Variable | Default | Description |
| --- | --- | --- |
| `ENABLE_POSTHOG_ANALYTICS` | `true` | Send product analytics events to OpenHands. |
| `POSTHOG_CLIENT_KEY` | OpenHands project key | PostHog project key. To send nothing, set `ENABLE_POSTHOG_ANALYTICS` to `false` and set this to an empty value. |
