Use ngrok to give the [Docker Compose](/enterprise/docker-compose) stack a public HTTPS URL. You
don't need to open any ports.

## Prerequisites

- The [Docker Compose prerequisites](/enterprise/docker-compose#prerequisites)
- ngrok, installed and connected to your ngrok account. Follow steps 1 and 2 of the
  [ngrok Agent CLI Quickstart](https://ngrok.com/docs/gateway/endpoints/agent-cli-quickstart).
- Your ngrok domain. Every ngrok account includes a free dev domain, such as
  `example-name.ngrok-free.app`. You can find it on the [Domains](https://dashboard.ngrok.com/domains)
  page of the ngrok dashboard.

## Install

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/OpenHands/enterprise.git
    cd enterprise
    ```
  </Step>
  <Step title="Configure the stack">
    Create a `.env` file in the `enterprise` directory. Replace `example-name.ngrok-free.app` with
    your ngrok domain:

    ```bash .env
    WEB_HOST=example-name.ngrok-free.app
    WEB_URL=https://example-name.ngrok-free.app
    AGENT_CANVAS_LOCK_TO_CLOUD=https://example-name.ngrok-free.app
    ```
  </Step>
  <Step title="Start the stack">
    ```bash
    docker compose up --wait
    ```
  </Step>
  <Step title="Start ngrok">
    ```bash
    ngrok http 3100 --url https://example-name.ngrok-free.app
    ```

    ngrok serves the stack at your domain while this command runs. Keep it running.
  </Step>
  <Step title="Complete onboarding">
    Open your ngrok URL and follow the onboarding flow to create your first user and configure
    your LLM provider. On a free ngrok account, ngrok shows a warning page first. Click **Visit**
    to continue.
  </Step>
</Steps>
