This guide runs the [Docker Compose](/enterprise/docker-compose) stack on a Linux VM and serves it
over HTTPS at your own domain. Caddy handles HTTPS. Caddy can get a certificate from Let's Encrypt
automatically, or it can use a certificate that you provide.

## Prerequisites

- A Linux VM with at least 4 CPUs, 16 GB of memory, and 100 GB of disk
- [Docker Engine](https://docs.docker.com/engine/install/) with the Compose plugin, and Git
- A domain name for OpenHands, such as `openhands.example.com`
- Ports 80 and 443 open to your users
- An API key from your LLM provider

## Install

<Steps>
  <Step title="Create a DNS record">
    Create a DNS A record that points your domain to the IP address of the VM.
  </Step>
  <Step title="Clone the repository">
    On the VM, run:

    ```bash
    git clone https://github.com/OpenHands/enterprise.git
    cd enterprise
    ```
  </Step>
  <Step title="Configure the stack">
    Create a `.env` file in the `enterprise` directory. Replace `openhands.example.com` with your
    domain.

    <Tabs>
      <Tab title="Automatic certificate">
        ```bash .env
        COMPOSE_FILE=docker-compose.yml:docker-compose.https.yml
        WEB_HOST=openhands.example.com
        WEB_URL=https://openhands.example.com
        AGENT_CANVAS_LOCK_TO_CLOUD=https://openhands.example.com
        ```

        Caddy gets a certificate from Let's Encrypt when the stack starts and renews it
        automatically. Let's Encrypt must be able to reach the VM from the internet on port 80 or
        443.
      </Tab>
      <Tab title="Your own certificate">
        ```bash .env
        COMPOSE_FILE=docker-compose.yml:docker-compose.https-own-cert.yml
        WEB_HOST=openhands.example.com
        WEB_URL=https://openhands.example.com
        AGENT_CANVAS_LOCK_TO_CLOUD=https://openhands.example.com
        ```

        Copy your certificate and private key into the `certs` directory:

        ```bash
        mkdir -p certs
        cp /path/to/fullchain.pem certs/cert.pem
        cp /path/to/privkey.pem certs/key.pem
        ```

        The certificate must be issued by a public certificate authority, and `cert.pem` must
        contain the full certificate chain.
      </Tab>
    </Tabs>

    `COMPOSE_FILE` adds a Caddy service that serves HTTPS on ports 80 and 443. Docker Compose
    reads this file on every command, so the commands on the
    [Docker Compose](/enterprise/docker-compose) page work without changes.
  </Step>
  <Step title="Start the stack">
    ```bash
    docker compose up --wait
    ```
  </Step>
  <Step title="Complete onboarding">
    Open `https://openhands.example.com` and follow the onboarding flow to create your first user
    and configure your LLM provider.
  </Step>
</Steps>

## Replace Your Certificate

If you use your own certificate, copy the new files to `certs/cert.pem` and `certs/key.pem`, then
restart Caddy:

```bash
docker compose restart https
```
