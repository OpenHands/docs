Set these values in the `values.yaml` for your release and apply them with `helm upgrade`.
Credentials come from Kubernetes Secrets in the release namespace. For those, the table names the
Secret and key.

To set an application environment variable that has no dedicated value, add it under `env`:

```yaml values.yaml
env:
  LOG_LEVEL: DEBUG
```

For the Docker Compose stack, see [Docker Compose Configuration](/enterprise/docker-compose/configuration).

## General

For DNS records and certificates, see [DNS and TLS](/enterprise/k8s-install/dns-and-tls).

| Setting | Default | Description |
| --- | --- | --- |
| `ingress.host` | | Hostname that users open OpenHands on, such as `app.openhands.example.com`. |
| `ingress.class` | `traefik` | Ingress class of your ingress controller. |
| `agent-canvas.enabled` | `false` | Run Agent Canvas. |
| `agent-canvas.staticServer.lockToCloud` | | URL that Agent Canvas connects to, such as `https://app.openhands.example.com`. |
| `env.PERMITTED_CORS_ORIGINS` | `https://<ingress.host>` | Comma-separated origins that can call the API from a browser. |
| `env.LOG_LEVEL` | `INFO` | Log level: `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |

## Database and Cache

The chart runs a bundled PostgreSQL by default. For production, we recommend your own PostgreSQL.
See [External PostgreSQL](/enterprise/external-postgres).

| Setting | Default | Description |
| --- | --- | --- |
| `postgresql.enabled` | `true` | Run the bundled PostgreSQL. Set it to `false` to use your own. |
| `postgresql.auth.database` | | Application database in the bundled PostgreSQL. |
| `postgresql.auth.username` | `postgres` | Database user for the bundled PostgreSQL. |
| `externalDatabase.enabled` | `false` | Set it to `true` when you use your own PostgreSQL. |
| `externalDatabase.host` | | Hostname of your PostgreSQL. |
| `externalDatabase.port` | `5432` | Port of your PostgreSQL. |
| `externalDatabase.database` | | Application database in your PostgreSQL. |
| `externalDatabase.username` | | Database user for your PostgreSQL. |
| `externalDatabase.sslMode` | `prefer` | PostgreSQL SSL mode, such as `require` or `verify-full`. |
| Secret `postgres-password`, key `password` | | Database password, for the bundled PostgreSQL or your own. |
| `databaseMigrations.migrate` | `true` | Migrate the database schema before the application starts. |
| `databaseMigrations.createDatabases` | `false` | Create the databases that OpenHands needs on the first start. |
| `redis.enabled` | `true` | Run the bundled Redis. |
| `valkey.enabled` | `false` | Run the bundled Valkey. Redis takes precedence when both are enabled. |
| Secret `redis`, key `redis-password` | | Password for the bundled Redis or Valkey. |

## Conversation Storage

Use an S3-compatible store or Google Cloud Storage. Google Cloud Storage uses the workload's service
account. For Amazon S3 on EKS, see [object storage](/enterprise/k8s-install/eks#object-storage).

| Setting | Default | Description |
| --- | --- | --- |
| `filestore.type` | `gcs` | Storage backend: `s3` or `gcs`. |
| `filestore.bucket` | `openhands-sessions` | Bucket for conversation files. |
| `filestore.region` | | AWS Region of the bucket. |
| `filestore.endpoint` | | Endpoint of an S3-compatible store other than Amazon S3, such as `https://s3.example.com`. Leave it empty for Amazon S3. |
| `filestore.existingSecret` | | Secret with the access key pair in `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` keys. Leave it empty to use the workload's AWS identity. |

## Authentication

The chart signs users in through Keycloak, which brokers sign-in to your Git provider or SAML
identity provider.

| Setting | Default | Description |
| --- | --- | --- |
| Secret `jwt-secret`, key `jwt-secret` | | Key that signs session tokens and encrypts stored secrets. To use a different Secret, set `sessions.existingSecret`. |
| `duplicateEmailCheck` | `true` | Reject a sign-in when another account has the same email address after its plus-address suffix is removed, such as `name+test@example.com`. |
| `env.REQUIRE_VERIFIED_EMAILS` | `false` | Reject a sign-in when the identity provider has not verified the user's email address. |
| `userProvisioning.enabled` | `false` | Turn on the admin API that creates users without their input. |
| `openOrgCreation.enabled` | `false` | Let any signed-in user create an organization. |

| `litellm-helm.proxy_config.model_list` | | Models that the bundled proxy serves. |
| Secret `litellm-env-secrets` | | Provider keys for the bundled proxy, such as `ANTHROPIC_API_KEY`. |
| `litellm.url` | | URL of your own LiteLLM proxy. The chart ignores it when `litellm-helm.enabled` is `true`. |
| Secret `lite-llm-api-key`, key `lite-llm-api-key` | | Master key of the LiteLLM proxy. |
| `litellm.teamId` | `openhands` | LiteLLM team for OpenHands users. OpenHands creates the team if it doesn't exist. |
| `env.LITELLM_DEFAULT_MODEL` | | Default model for new users, such as `litellm_proxy/claude-sonnet-4-5`. |
| `env.ENABLE_LEGACY_LITELLM` | `true` | Route LLM requests through the LiteLLM proxy, which manages each user's key and budget. |

## Sandboxes

The chart runs sandboxes through the Runtime API. For sandbox CPU and memory, see
[Resource Limits](/enterprise/k8s-install/resource-limits).

| Setting | Default | Description |
| --- | --- | --- |
| `sandbox.apiHostname` | | URL of the Runtime API, such as `https://runtime-api.openhands.example.com`. |
| Secret `sandbox-api-key`, key `sandbox-api-key` | | Key that the application uses to call the Runtime API. It must match the `default-api-key` Secret. |
| `runtime-api.ingress.host` | | Hostname of the Runtime API, such as `runtime-api.openhands.example.com`. |
| `runtime-api.sandbox_namespace` | Release namespace | Namespace for sandboxes. We recommend a dedicated namespace. |
| `runtime-api.env.RUNTIME_BASE_URL` | | Domain that sandbox hostnames end with, such as `runtime.openhands.example.com`. |
| `runtime-api.env.RUNTIME_URL_SEPARATOR` | `.` | Separator between the sandbox ID and `RUNTIME_BASE_URL` in sandbox hostnames. |
| `runtime-api.env.RUNTIME_DISABLE_SSL` | `true` | Serve sandbox URLs over HTTP. Set it to `false` to serve them over HTTPS. |
| `runtime-api.env.STORAGE_CLASS` | `standard-rwo` | Storage class for sandbox volumes. Set it to a class from `kubectl get storageclass`. |
| `env.OH_SANDBOX_MAX_NUM_SANDBOXES` | `10` | Maximum number of sandboxes that each user can run at once. When a user starts another sandbox, OpenHands pauses their oldest running one. |
| `global.agentServerEnv` | | Environment variables for every sandbox, as a map. |
