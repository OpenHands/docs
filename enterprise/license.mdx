Only Super Admins can manage the license for an OpenHands Enterprise installation. Get a license key from
[Customer Center](/enterprise/customer-center).

## First-Time Installs

On a new [Docker Compose or Helm](/enterprise/overview) installation, the
[setup wizard](/enterprise/super-admin#first-install-setup) asks for your license key when the first Super Admin signs
in. Enter your license key there.

### Alternative: Set License Key in Your Configuration

Instead of using the setup wizard, you can set the license key in your installation's configuration:

<Tabs>
  <Tab title="Helm">
    Add the license key to your `values.yaml`:

    ```yaml values.yaml
    license:
      key: "<license-key>"
    ```

    Then apply it with `helm install`, or with `helm upgrade` on an existing release. The chart stores the key in the
    `openhands-license` Secret and passes it to OpenHands as `OPENHANDS_LICENSE_KEY`.

    - For an installation that can't reach Customer Center, pass an offline license file instead with
      `--set-file license.offlineLicense=<path-to-license-file>`.
    - To use a Secret you manage, set `license.existingSecret` to its name. The Secret needs a `license-key` or
      `offline-license` entry. Restart the `openhands` pods after you change the Secret.
  </Tab>
  <Tab title="Docker Compose">
    Add the license key to the `.env` file in the `enterprise` directory:

    ```bash .env
    OPENHANDS_LICENSE_KEY=<license-key>
    ```

    Then restart the stack:

    ```bash
    ./scripts/setup.sh
    ```
  </Tab>
</Tabs>

For all license variables, see [Environment Variables](/enterprise/environment-variables#license). A license set in
your installation's configuration takes precedence over the `License` page in the Super Admin Dashboard and can't be
changed there.

## Existing Installs

We recommend adding or changing the license in the Super Admin Dashboard:

1. Open `Settings`.
2. Click your name in the lower left, then click `Super Admin Dashboard`.
3. Click `License` in the navigation.
4. Enter your license key, or upload your offline license file.

You can also set the license in your installation's configuration:

- **Helm or Docker Compose**: Follow [Alternative: Set License Key in Your Configuration](#alternative-set-license-key-in-your-configuration).
- **Replicated VM**: In the [Admin Console configuration](/enterprise/vm-install/admin-console-configuration#open-the-configuration-screen),
  open the `License` section. Choose a `License Type`, enter your `License Key` or upload your offline license file,
  then [apply the change](/enterprise/vm-install/admin-console-configuration#apply-a-configuration-change).
