Install OpenHands Enterprise with Replicated Embedded Cluster on a dedicated VM.
Choose the guide for your infrastructure:

<CardGroup cols={2}>
  <Card title="AWS Quick Start" icon="aws" href="/enterprise/vm-install/aws">
    Provision AWS infrastructure with the official Terraform module, then install and configure OpenHands.
  </Card>
  <Card title="Google Cloud Quick Start" icon="google" href="/enterprise/vm-install/google">
    Provision a Compute Engine VM and configure administrator-managed Vertex AI models.
  </Card>
  <Card title="Azure Quick Start" icon="microsoft" href="/enterprise/vm-install/azure">
    Provision an Azure VM, start with Anthropic and optionally configure administrator-managed Azure OpenAI models.
  </Card>
  <Card title="Generic VM Quick Start" icon="server" href="/enterprise/vm-install/generic-vm">
    Prepare a Linux VM on-premises or on another cloud provider, then install and configure OpenHands.
  </Card>
</CardGroup>

Each guide covers prerequisites, infrastructure, preflights, installation,
application configuration and first-login checks. For an existing Kubernetes
cluster, see [Install with Helm](/enterprise/k8s-install/installation).

The [Sizing Guide](/enterprise/sizing-guide) helps you choose resources for your
workload. The [Admin Console Configuration reference](/enterprise/vm-install/admin-console-configuration)
covers deployment settings and optional integrations.
