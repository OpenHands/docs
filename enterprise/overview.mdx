OpenHands Enterprise runs on your own infrastructure. You run the same application that powers
OpenHands Cloud, and your code, conversations, and LLM traffic stay in your environment.

## Deployment options

| Best for | Deployment | Runs on |
|----------|------------|----------------|
| Trials and proofs of concept | [Docker Compose](/enterprise/docker-compose) | A single machine, without high availability, scaling, or backups |
| Production | [Kubernetes (Helm)](/enterprise/k8s-install/index) | Your Kubernetes cluster, with high availability and sandbox scaling |

We recommend Docker Compose to evaluate OpenHands Enterprise and Kubernetes for production.

## Docker Compose

The Docker Compose stack runs OpenHands Enterprise on a single machine.

Use it to try OpenHands Enterprise with a small group of users. It does not provide high
availability, scaling, or backups, and it does not include every Enterprise feature.

## Kubernetes

For production, we recommend installing OpenHands Enterprise into a Kubernetes cluster with Helm.
This deployment supports SSO, external PostgreSQL and object storage, sandbox scaling, and the
full set of [integrations](/enterprise/integrations/overview).

Before you install, size your cluster with the [Sizing Guide](/enterprise/sizing-guide). We
provide setup guides for [Amazon EKS](/enterprise/k8s-install/eks),
[Azure AKS](/enterprise/k8s-install/aks), and [Google GKE](/enterprise/k8s-install/gke).

## Architecture

OpenHands Enterprise consists of the application services, a PostgreSQL database, and isolated
sandboxes where agents run code. You connect it to your own LLM provider and source control.
