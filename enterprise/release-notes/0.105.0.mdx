# OpenHands Enterprise 0.105.0

Released November 12, 2026.

## Highlights

- **License management** — Super Admins can enter a license key on the new **Super Admin > License** page or during first-time install wizard. License Enforcement ships "off" in this release. Existing OpenHands Enterprise customers will receive their license key in coming weeks to ensure continued operation with no change in limits of functionality.
- **Super Admin feature switches** — The Super Admin dashboard is now on by default. Agent Profiles and Organization MCP Servers (both beta) can be turned on from **Super Admin > Instance Settings** without a restart.
- **Agent profiles for every automation** — Any automation can now run with a chosen agent profile, including preset and plugin automations.
- **Better MCP server settings** — Users can name and rename remote MCP servers and turn each server on or off. The MCP Library now offers the organization scope for stdio servers.
- **Optional LiteLLM gateway for Docker Compose** — Compose installs can add a LiteLLM gateway for per-user and per-organization budgets.

## Upgrade Notes

- **Super Admin dashboard turns on** — Replicated installs that never set *Enable Super Admin Dashboard* get it turned on when they upgrade. The first-install wizard does not start on existing installs. Installs that turned the option off keep it off.
- **License preflight warning** — Installs without a license now get a preflight warning, and automatic updates wait until a license is set. A headless `openhands install` without a license needs `--ignore-app-preflights`. Deploying from the Admin Console still works.
- **Helm installs: new Enterprise defaults** — Helm now hides personal LLM-key editing and the Billing page, and turns off email changes. Local Automations is on by default. It needs a durable PostgreSQL database, an `s3` or `gcs` package store, and `automation.upgradeAcknowledged: true` on upgrade. The Replicated SDK is now off by default for chart installs from ghcr; the VM installer keeps it on.
- **New bundled MinIO bucket** — Installs that use the bundled MinIO get one extra empty bucket, `runtime-api-workspaces`, for the opt-in FUSE workspace storage.
- **VS Code in sandboxes now uses code-server** — Coder code-server replaces OpenVSCode Server for the in-sandbox editor.
