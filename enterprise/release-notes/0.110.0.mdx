# OpenHands Enterprise 0.110.0

Released November 17, 2026.

## Highlights

- **Agent Canvas on by default for Helm installs** — Helm installs now run Agent Canvas at `/canvas`, as Replicated and Docker Compose installs already do.
- **Super Admin dashboard on by default for Helm installs** — Fresh Helm installs show the Super Admin dashboard, and the first user to sign in becomes the first Super Admin. Super Admins also get a link to the dashboard at the top of the Settings navigation.
- **Docker Compose setup script** — `scripts/setup.sh` starts the Compose stack and prints the URL to open and the log commands.
- **Organization conversation usage detail** — Organization Owners and Admins can opt in to a read-only API that breaks a conversation's usage into the main agent, sub-agent tasks, and the condenser.
- **Automations no longer drop blocked runs** — A run that hits a limit is deferred instead of dropped.

## Upgrade Notes

- **Helm installs: Agent Canvas turns on** — On upgrade, Helm installs get an Agent Canvas pod and a `/canvas` route, locked to your install. No stored data changes. Set `agent-canvas.enabled: false` to turn it off. To run Canvas on its own host, set `authRequired` or `lockToCloud`, or the chart fails to render.
- **Helm installs: Super Admin dashboard turns on** — The chart sets `env.ENABLE_SUPER_ADMIN: "true"`. Set it to `"false"` to turn the dashboard off. Installs that already have users do not run the first-install setup again. If your install sets any `OH_WEB_CLIENT_FEATURE_FLAGS_*` variable, also set `OH_WEB_CLIENT_FEATURE_FLAGS_ENABLE_SUPER_ADMIN`.
- **Helm installs: personal workspaces are hidden** — The chart sets `HIDE_PERSONAL_WORKSPACES: "true"`. Members of the default organization move into it when they sign in, and conversations stored in a personal workspace open the launcher instead. Nothing is deleted. To keep personal workspaces, set `HIDE_PERSONAL_WORKSPACES: "false"` before you upgrade.
- **Replicated and Docker Compose installs** — These installs already use the Agent Canvas and Super Admin defaults, and Replicated installs set `HIDE_PERSONAL_WORKSPACES` from their own config.
- **Super Admin user deletion sends an email** — `DELETE /api/admin/directory/users/{user_id}` now emails the deleted user by default. Pass `?notify=false` to skip the email.
