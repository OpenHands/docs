# OpenHands Enterprise 0.36.1

Released September 23, 2026.

## Highlights

- **Session Preservation** — Fixed user session handling during transient network failures
- **Email Configuration** — Deployments can now disable email changes
- **Stability Focus** — Patch release concentrated on Enterprise Server fixes
