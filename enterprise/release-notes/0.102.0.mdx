# OpenHands Enterprise 0.102.0

Released November 6, 2026.

## Highlights

- **Multi-repository conversations** — Start a conversation with several repositories from the web app, or by naming them in a Slack message or a Jira or Jira Data Center ticket. The agent can read files, diffs, skills, and hooks from every repository, and a credential helper lets it clone private repositories from any connected git provider.
- **Model Routing** — Organization admins can create a Model Router on a new organization settings page; once activated, it picks the model for each conversation. Turn it off from **Enable Model Routing** under the new **Agent Features** section of the Admin Console (on by default).
- **Bitbucket Data Center** — Bitbucket Data Center can be added as a git provider from the Super Admin dashboard, sandboxes can clone its repositories, and its pull request events reach automations.
- **Service accounts (beta)** — Super Admins can turn on service accounts from the Instance page, then manage them on a new settings page and run automations under them instead of a personal account.
- **Installation and security** — Serve a customer-managed TLS secret, apply an opt-in egress NetworkPolicy to sandboxes, and restrict password login to permitted email patterns. Git tokens stay out of sandbox clone URLs, bash event files are encrypted at rest, and the agent-server images ship fixes for the emSign certificate authorities and a Node.js Brotli CVE.

## Upgrade Notes

- **Public conversation links from organizations now require org membership** — A conversation shared publicly from a team organization can only be opened by signed-in members of that organization. Links shared from a Personal Workspace remain open to anyone with the link.
- **The Azure DevOps Organization setting is removed** — Azure DevOps now discovers the organizations each user belongs to and works in all of them, so the **Azure DevOps Organization** Admin Console field (`azureDevOps.organization` for Helm) is gone. An existing value is ignored; no action is needed.
- **Docker Compose now listens on port 9043** — The Docker Compose stack's default port moves from `3100` to `9043` so that it no longer conflicts with Agent Canvas. Update bookmarks, tunnels, and redirect URLs, or set `APP_PORT=3100` to keep the old port.
