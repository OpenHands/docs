# OpenHands Enterprise 0.102.0

Released November 6, 2026.

## Highlights

- **Multi-Repository Conversations** — Start a conversation with several repositories from the web app, Slack, Jira, or Jira Data Center. The agent can clone private repositories from any connected git provider.
- **Model Routing** — Organization admins can create a Model Router that picks the model for each conversation. It is on by default; turn it off with **Enable Model Routing** in the Admin Console.
- **Bitbucket Data Center** — Add Bitbucket Data Center as a git provider and trigger automations from its pull request events.
- **Service Accounts (Beta)** — Super Admins can turn on service accounts from the Instance page and run automations under them instead of a personal account.
- **Installation and Security** — Use your own TLS certificate secret, restrict sandbox egress with an opt-in NetworkPolicy, and limit password login to permitted email patterns. Images now distrust the compromised emSign certificate authorities.

## Upgrade Notes

- **Public conversation links require organization membership** — A conversation shared publicly from an organization can now be opened only by signed-in members of that organization. Links shared from a Personal Workspace are unchanged.
- **Azure DevOps Organization setting removed** — Azure DevOps now works across every organization a user belongs to, so this Admin Console field is gone. No action is needed.
- **Docker Compose port changed to 9043** — The stack no longer conflicts with Agent Canvas on `3100`. Update bookmarks and tunnels, or set `APP_PORT=3100` to keep the old port.
