# OpenHands Enterprise 0.81.0

Released October 13, 2026.

## Highlights

- **Super Admin Dashboard (Beta)** — A new dashboard at `/super-admin` lets instance Super Admins manage users, organizations, and membership across the whole installation, and walks the first Super Admin through a guided setup on a new install. The feature is currently in Beta, and off by default. Turn it on with **Enable Super Admin Dashboard** in the Admin Console. A future release will enable this on by default.
- **Security Updates** — The Enterprise Server, Runtime API, and Automation images drop packages with known high and critical vulnerabilities.
- **Automation Improvements** — The automations list can be filtered by creator, custom webhook deliveries are no longer processed twice, and the 64 KiB limit on total automation state is gone.
