The Docker Compose stack runs OpenHands Enterprise on a single machine. Use it to evaluate
OpenHands Enterprise with a small group of users. For production, we recommend
[Kubernetes](/enterprise/k8s-install/index).

## Prerequisites

- Git
- Docker and Docker Compose
- An API key from your LLM provider

## Install

<Steps>
  <Step title="Start the stack">
    ```bash
    git clone https://github.com/OpenHands/enterprise.git
    cd enterprise
    docker compose up --wait
    ```

    The command returns when every service is healthy. On the first start, the application pulls
    images, which can take several minutes.
  </Step>
  <Step title="Complete onboarding">
    Open [http://localhost:9043](http://localhost:9043) and follow the onboarding flow to create
    your first user and configure your LLM provider.
  </Step>
</Steps>

## Telemetry

The stack sends a small set of product analytics events to OpenHands' PostHog project so we can
measure the first-install experience: the first Super Admin's registration (work email), the
company and organization names entered during setup, and automation creation (automation name).
To send nothing, set `ENABLE_POSTHOG_ANALYTICS=false` in a `.env` file next to `docker-compose.yml`
and set `POSTHOG_CLIENT_KEY` to an empty value, then restart the stack.

## Share with your team

By default, the stack is only reachable from the machine it runs on. To share it with others,
serve it over HTTPS with [ngrok](/enterprise/docker-compose/ngrok) or run it on a
[VM with your own domain](/enterprise/docker-compose/https).

## Upgrade

Pull the latest changes, then restart the stack:

```bash
git pull
docker compose down
docker compose up --wait
```

The application migrates its database on startup.

## Stop and reset

Stop the stack with:

```bash
docker compose down
```

Your data is stored in Docker volumes and is kept when you stop the stack.

### Reset

To delete all data and start over, stop any running sandbox containers, then remove the volumes:

```bash
docker compose down -v
```
