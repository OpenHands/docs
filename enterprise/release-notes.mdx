OpenHands Enterprise release notes document new features, bug fixes, and improvements for each version. Each release includes updates across multiple components including the Enterprise Server, Software Agent SDK, Runtime API, OpenHands Canvas, and Helm Chart.

## Latest Releases

### [Release 0.70.0](/enterprise/releases/0.70.0)

Key highlights:
* **Refreshed UI** — Updated conversation and Settings experiences now align with OpenHands Agent Canvas
* **Organization-Scoped Secrets** — Admins can create shared secrets for use across the Organization
* **User Budget Dashboard** — Users can view their usage and monthly budget consumption
* **OAuth MCP Support** — Users can authenticate to MCP servers with OAuth
* **Organization-Visible Automations** — Users can see Automations across their Organization
* **Automation Git Sync** — Admins can sync Automations with a Git repository

### [Release 0.64.0](/enterprise/releases/0.64.0)

Key highlights:
* Azure DevOps integration support
* Bitbucket Data Center integration
* Jira Cloud and Data Center integrations
* Enhanced automation capabilities

### [Release 0.55.0](/enterprise/releases/0.55.0)

Key highlights:
* Slack integration
* Enhanced MCP server support
* Improved runtime management
* Bug fixes and stability improvements
