Choose where you want to run agents. If you're not sure, start with Agent Canvas on your own machine or with
OpenHands Cloud. See the [Introduction](/overview/introduction) to compare products.

<CardGroup cols={2}>
  <Card title="Agent Canvas" icon="desktop" href="/openhands/usage/agent-canvas/setup">
    Install the open-source workspace with npm, npx, or Docker and run agents on your own machine.
  </Card>
  <Card title="OpenHands Cloud" icon="cloud" href="https://app.all-hands.dev">
    Sign in to the free hosted version. No installation required.
  </Card>
  <Card title="OpenHands Enterprise" icon="building" href="/enterprise/overview">
    Deploy OpenHands on your own infrastructure for your organization.
  </Card>
  <Card title="Software Agent SDK" icon="code" href="/sdk/getting-started">
    Build your own agents in Python.
  </Card>
</CardGroup>

After you start your first conversation, read [Tutorials](/openhands/usage/get-started/tutorials) and
[Good vs. Bad Instructions](/openhands/usage/essential-guidelines/good-vs-bad-instructions), then
[create an automation](/openhands/usage/automations/creating-automations).
